# Customer Segmentation Analysis Using K-Means Clustering

## Task 2 – Oasis Infobyte Internship

## Project Overview

Customer segmentation is a machine learning technique used to divide customers into groups based on shared characteristics and spending behaviour.

This project applies the **K-Means clustering algorithm** to segment customers using demographic information and spending-related features. The analysis helps identify customer groups that can be targeted with personalised marketing campaigns.

The project is implemented using Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, and Jupyter Notebook.

## Objectives

- Load and inspect the customer dataset.
- Handle missing values, duplicate records, and inconsistent data.
- Perform exploratory data analysis and descriptive statistics.
- Select relevant customer features for clustering.
- Encode categorical variables and standardise numerical features.
- Determine the optimal number of clusters using the Elbow Method.
- Evaluate cluster quality using silhouette scores.
- Apply K-Means clustering to identify customer segments.
- Visualise customer groups using scatter plots and bar charts.
- Profile customer segments and recommend marketing strategies.

## Dataset Description

The project uses three CSV files:

| File                   | Description                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| `train.csv`            | Customer records, including demographic features and existing segmentation labels.                   |
| `test.csv`             | Customer records used to apply the trained clustering model or predict existing segmentation labels. |
| `sample_submisson.csv` | Template specifying the expected submission format.                                                  |

### Dataset Features

| Feature           | Description                                           |
| ----------------- | ----------------------------------------------------- |
| `ID`              | Unique customer identifier.                           |
| `Gender`          | Customer's gender.                                    |
| `Ever_Married`    | Whether the customer has ever been married.           |
| `Age`             | Customer's age.                                       |
| `Graduated`       | Whether the customer has graduated.                   |
| `Profession`      | Customer's profession.                                |
| `Work_Experience` | Customer's work experience.                           |
| `Spending_Score`  | Customer's spending category.                         |
| `Family_Size`     | Number of family members.                             |
| `Var_1`           | Additional customer category.                         |
| `Segmentation`    | Existing customer segment label in the training data. |

**Note:** The dataset does not contain transaction-level information such as purchase dates, order counts, or purchase amounts. Therefore, traditional RFM analysis, average purchase value, purchase frequency, and monetary customer lifetime value cannot be calculated directly.

Instead, the project uses the available demographic and spending-related features for customer segmentation.

## Methodology

### 1. Data Loading and Inspection

The three CSV files are loaded using Pandas. The dataset is inspected to understand its structure, feature types, missing values, and duplicate records.

### 2. Data Cleaning

- Standardise column names.
- Remove duplicate records.
- Handle missing numerical values using median imputation.
- Handle missing categorical values using an explicit fallback category.
- Convert numerical fields to suitable data types.

### 3. Exploratory Data Analysis

Descriptive statistics and visualisations are used to explore age, family size, work experience, spending score, and existing segmentation labels.

### 4. Feature Selection

The model uses relevant demographic and spending-related features, including:

- Age
- Spending Score
- Family Size
- Work Experience
- Gender
- Marital Status
- Graduation Status
- Profession
- Additional customer category

The `ID` field is excluded because it is an identifier. The existing `Segmentation` label is excluded from K-Means inputs to prevent label leakage.

### 5. Data Preprocessing

Numerical features are imputed and standardised using `StandardScaler`. Categorical features are imputed and encoded using `OneHotEncoder`.

### 6. Optimal Cluster Selection

The Elbow Method is used to evaluate different values of K by comparing their inertia. Silhouette scores provide an additional measure of cluster separation.

### 7. K-Means Clustering

K-Means groups customers based on distances between their preprocessed feature vectors. The number of clusters is selected after examining the evaluation plots.

### 8. Cluster Visualisation

The notebook generates:

- Age versus Family Size scatter plot.
- Age versus Work Experience scatter plot.
- Optional Age versus Spending Score scatter plot.
- Bar chart showing the number of customers per cluster.
- Cluster profile tables and visual comparisons.

### 9. Cluster Profiling

Cluster-level statistics and categorical distributions are analysed to understand differences between customer groups.

### 10. Marketing Recommendations

Marketing strategies are proposed based on the observed customer profiles and spending patterns.

## Key Evaluation Methods

### Elbow Method

The Elbow Method examines how K-Means inertia changes as the number of clusters increases. The selected K should balance cluster compactness and interpretability.

### Silhouette Score

The silhouette score evaluates how well-separated the resulting clusters are. Higher values generally indicate better separation, although the score should be considered alongside business relevance.
